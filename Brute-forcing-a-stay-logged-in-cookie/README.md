Brute-forcing a Stay-Logged-In Cookie

Platform: PortSwigger Web Security Academy

Topic: Authentication Vulnerabilities

Level: Practitioner

Author: Kali Man

📌 Lab Overview

This repository documents the analysis and exploitation of a poorly implemented "Stay logged in" cookie mechanism in the PortSwigger Web Security Academy.

The goal of this lab is to bypass authentication and gain unauthorized access to the user account carlos by reverse-engineering the cookie format and executing a targeted brute-force attack using Burp Suite.

🔍 Vulnerability Breakdown

The application implements a persistent session mechanism vulnerable to brute forcing
